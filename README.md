# 찾기카드

사진과 확인된 정보를 입력해 SNS에 바로 공유할 수 있는 정사각형 실종자 카드를 만드는 웹 도구입니다.

## 원칙

- 사진과 입력 정보는 서버로 보내거나 저장하지 않습니다.
- 카드 이미지는 사용자의 브라우저에서만 생성됩니다.
- 생성 과정에서 새 PNG로 변환하므로 원본 사진의 EXIF 위치 정보는 결과물에 포함되지 않습니다.
- 별도 회원가입, 데이터베이스, 분석 도구를 사용하지 않습니다.

## 사용 방법

1. `정보 수정`에서 사진과 확인된 정보를 입력합니다.
2. 정사각형 공유 카드를 확인합니다.
3. `이미지 저장·공유`를 눌러 기기의 공유 기능을 열거나 PNG를 저장합니다.

## 안전 안내

이 프로젝트는 경찰청 또는 정부기관의 공식 서비스가 아니며 실종 신고를 대체하지 않습니다. 긴급한 상황은 먼저 112에 신고하세요. 당사자 또는 보호자의 동의를 확인하고, 공개가 꼭 필요한 정보만 사용하며, 발견 후에는 게시물을 신속히 내려 주세요.

## 개발

```bash
npm ci
npm run dev
```

검증 및 빌드:

```bash
npm run check:runtime
npm run build
npm run build:pages
```

`main` 브랜치에 푸시하면 GitHub Actions가 `dist/pages`를 GitHub Pages에 배포합니다.
